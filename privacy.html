Privacy

This statement covers nqtn.me, the website of Not Quite Tech Pty Ltd.

This website

nqtn.me is a static website. It does not use cookies or advertising, and it does not load fonts from third parties.

We count visits with GoatCounter, a privacy-friendly analytics service. When a page loads, a small script sends GoatCounter the page address, the referring site, the browser and screen size, and the country derived from your IP address. GoatCounter does not set cookies, does not store IP addresses, and does not track you across sites. We use the totals only to see which pages people read.

Like any website, the server that hosts it may keep standard request logs (such as IP address, browser type and the page requested) for security and operation.

Our products

Each of our products has its own privacy policy, published on that product’s website and, for apps, on its App Store listing.
